# Fieldnote Social Feed

A lightweight, responsive social feed demo built with plain HTML, CSS, and JavaScript. Fieldnote features an interactive post, likes, comments, and a persistent light/dark theme toggle.

## Technologies

- HTML5 for semantic page structure
- CSS3 for responsive layout, styling, and light/dark themes
- Vanilla JavaScript for likes, comments, and theme preferences
- Google Fonts and Unsplash for typography and photography

## Setup

No package installation or build step is required.

1. Clone or download this repository.
2. Open `index.html` in a modern web browser.

Alternatively, serve the project locally from its root directory:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`. Google Fonts and Unsplash photography are loaded remotely, so an internet connection is needed to display those assets.

## Features

- Responsive social post with author details and photography
- Like button that toggles its state and updates the like count
- Comment form that adds comments and updates the comment count
- Light and dark themes, with the system preference used by default
- Theme selection saved in browser storage between visits
- Accessible labels and keyboard focus styles for interactive controls
